01 / ARCHITECTURE

Real above.
Simulated below.

Applications use ordinary sockets. The Linux kernel handles transport. simulation controls the changing network models (L3-L1) between endpoints.

Keep the software real.
Make the conditions repeatable.

Each satellite endpoint runs in a Docker container with a real Linux TCP/IP stack. No simulation API. No simulation-aware application code.

Linux TAP interfaces carry Ethernet frames into the simulation, where routing, link behavior, and channel conditions determine when—and whether—packets arrive.

ENDPOINT, NOT TRANSIT

One host address. One default route to its simulation router. IP forwarding disabled in the container.
